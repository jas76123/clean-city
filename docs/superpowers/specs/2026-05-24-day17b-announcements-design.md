# Day 17B — AnnouncementsPage (веб-админка)

**Дата:** 2026-05-24
**Статус:** дизайн утверждён, готов к плану реализации
**Контекст:** День 17, пункт 17B. Бэкенд CRUD объявлений закрыт (Spec 2, 2026-05-13).

## Цель

Заменить заглушку `SectionPlaceholder` на маршруте `/announcements` рабочей
страницей: админ публикует объявление и снимает опубликованные с публикации.
Публикация рассылает push жителям выбранных районов (триггер уже на бэкенде).

## Объём (scope)

Поддерживаемые операции:

- **Создание** — `POST /announcements`
- **Список** — `GET /announcements`
- **Снятие с публикации** — `DELETE /announcements/{id}` (soft-delete:
  `expires_at = NOW()`)

Редактирование (`PATCH /announcements/{id}`) **не реализуется** — эндпоинт
существует, но в UI не задействован. Опечатку исправляют снятием и повторной
публикацией.

## Бэкенд (готов, не меняется)

| Метод | Эндпоинт | Доступ | Поведение |
|-------|----------|--------|-----------|
| `GET` | `/announcements?district=&limit=` | все (auth optional) | только **активные** (опубликованы, не истёк `expires_at`) |
| `POST` | `/announcements` | ADMIN / OPERATOR / INSPECTOR | создаёт + триггерит push жителям районов |
| `DELETE` | `/announcements/{id}` | ADMIN / OPERATOR / INSPECTOR | `expires_at = NOW()` |

Поля объявления:

- `title` — обязательно, ≤ 300 символов
- `body` — обязательно, ≤ 5000 символов
- `iconStyle` — `INFO` | `SUCCESS` | `WARNING`, по умолчанию `INFO`
- `category` — `ProblemCategory?`, **не используется в этой странице**
- `districts` — `List<String>`; пустой список бэкенд сохраняет как `ALL`
- `expiresAt` — `String?`, ISO-8601 **с offset**; пусто = бессрочно

Ключевые ограничения:

- Эндпоинт списка возвращает **только активные** объявления. После снятия с
  публикации (или после истечения срока) объявление исчезает из списка —
  отдельного архива нет. Это ожидаемое поведение.
- Пагинации нет, только `limit`. Поле `total` в ответе информационное.

## Форма создания

Карточка «Новое объявление», кнопка «Опубликовать» в шапке.

| Поле | Контрол | Валидация (зеркало бэкенда) |
|------|---------|------------------------------|
| Заголовок | text input | обязательно, ≤ 300 символов |
| Текст объявления | textarea | обязательно, ≤ 5000 символов |
| Тип | 3 кнопки-переключателя: Инфо / Успех / Предупреждение | по умолчанию `INFO` |
| Районы | переключатель «Все районы» + 4 чекбокса | см. ниже |
| Срок действия | date input + «Без срока» | необязательно |

Поля «Категория» в форме **нет**. Счётчиков символов **нет**.

### Поведение формы

- Кнопка «Опубликовать» заблокирована, пока заголовок или текст пустые
  (после `trim`), и пока идёт запрос.
- **Районы:** при включённом «Все районы» чекбоксы районов скрыты/неактивны, в
  запрос уходит `districts: []`. При выключенном — отправляются отмеченные
  районы; если не отмечен ни один, кнопка «Опубликовать» заблокирована.
- **Срок действия:** HTML `date` конвертируется в ISO-8601 на конец выбранного
  дня (`23:59:59`) с offset таймзоны Сочи (`+03:00`), т.к. бэкенд требует
  offset. Пустое поле → `expiresAt` не отправляется (бессрочно).
- При успехе: `toast.success('Объявление опубликовано')`, форма сбрасывается в
  начальное состояние, запрос `['announcements']` инвалидируется.
- Под формой — подсказка, что жителям выбранных районов уйдёт push.

## Список и снятие с публикации

Карточка «Опубликованные объявления» под формой. Элемент списка (по мокапу):

- Цветная иконка слева по `iconStyle`: `INFO` → синий, `SUCCESS` → зелёный,
  `WARNING` → янтарный.
- Заголовок, текст, мета-строка:
  `Опубликовано: <дата> · <районы или «Все районы»>`.
- Кнопка «Снять с публикации» справа.

### Поведение списка

- Данные через `useAnnouncementsQuery()` с `limit=100` (пагинации нет; для
  админки 100 с запасом). Автообновление раз в минуту (`refetchInterval`
  60 000 мс), `placeholderData: keepPreviousData` — как в `ComplaintsPage`.
- Состояния: загрузка («Загрузка…»), ошибка (текст + кнопка «Повторить»),
  пусто («Объявлений пока нет»).
- **Снятие — инлайн-подтверждение в карточке:** клик по «Снять с публикации»
  превращает кнопку в «Точно снять? · Да · Отмена». «Да» → `DELETE /{id}`;
  «Отмена» возвращает исходную кнопку. Отдельного диалога нет.
- При успехе снятия: `toast.success('Снято с публикации')`, инвалидация
  `['announcements']`. Объявление исчезает из списка (эндпоинт отдаёт только
  активные).

## Слой данных

`api/announcements.ts` — три функции поверх axios-клиента `api`:

- `listAnnouncements()` → `GET /announcements?limit=100`
- `createAnnouncement(req)` → `POST /announcements`
- `unpublishAnnouncement(id)` → `DELETE /announcements/{id}`

`hooks/announcementQueries.ts` — TanStack Query, `queryKey: ['announcements']`:

- `useAnnouncementsQuery()` — `refetchInterval` 60 000 мс,
  `placeholderData: keepPreviousData`
- `useCreateAnnouncementMutation()` — `onSuccess` инвалидирует `['announcements']`
- `useUnpublishAnnouncementMutation()` — `onSuccess` инвалидирует `['announcements']`

## Обработка ошибок

Через существующий `extractApiError`:

- **create:** 400 (валидация) → `toast.error` с текстом бэкенда; 403 (роль без
  прав) → `toast.error('Недостаточно прав для публикации')`; сеть/прочее →
  общий `toast.error`.
- **unpublish:** 404 (уже снято кем-то параллельно) → `toast` + инвалидация
  списка; 403 → `toast.error('Недостаточно прав')`; прочее → общий `toast`.
